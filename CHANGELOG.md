# Changelog

## 0.1.0 (2026-10-28)

- First release: a forwarding client for the hosted Goldseam MCP server, which publishes United States learning data for read-only querying. This is a labelled subset: 51 of the 57 captured tools are registered — the published-dataset surface and the structured comparators — while the six personal-evidence ingestion tools (`assemble_my_formal_education`, `assemble_my_work_and_credentials`, `assert_my_life_experiences`, `my_selfie_ksa_view`, `draft_my_claims`, `suggest_credit_for_my_learning`) are deliberately omitted. Tools/list is answered locally from the captured definitions, and every tools/call is forwarded upstream over a streamable-HTTP JSON-RPC session (initialize, notifications/initialized, tools/call, honouring the Mcp-Session-Id header when the upstream issues one).
- Tools cover certifications and their issuers and occupations, the KSA Dictionary and the CIP/SOC crosswalk, institutions, programs, learning units, checklists, catalogs, published academic policies, articulation and transfer agreements, pathways, comparability bundles, transfer frameworks, the CourseShelf census and demo-persona transcripts, plus comparators that run published rules over caller-supplied structured items (`will_my_credits_transfer`, `comparable_map`, `checklist_map`, `comparability_for_courses`, `compare_my_school`, `find_my_best_pathway`).
- Upstream results pass through verbatim, including the isError flag; upstream failures surface as `learnindex error:` text results.
- One bin serves the CLI (one subcommand per kept tool, plus `--version`) and the stdio MCP server (`mcp` subcommand). The upstream endpoint can be overridden via `GOLDSEAM_MCP_URL`. The registry record declares no headers on the remote, so no auth header is ever sent.
